[![Checks](https://img.shields.io/github/actions/workflow/status/MBAR-Millibar/Code-of-Conduct/checks.yml?branch=main&style=for-the-badge&label=checks)](.github/workflows/checks.yml)

The Code of Conduct for the Millibar.io online community and company. It is one
document used everywhere: our website, apps, community channels, GitHub
repositories and events.

**➡️ [Read the Code of Conduct](CODE_OF_CONDUCT.md)**

## 🚨 Need to report something?

**Do not open a GitHub issue.** Email
**[conduct@millibar.io](mailto:conduct@millibar.io)** or talk to any team member
you trust. See [Reporting](CODE_OF_CONDUCT.md#reporting) for how we handle
reports. Issues and pull requests in this repository are only for improving the
text of the code itself.

## 🧩 Using this code in a Millibar repository

Link to the canonical file instead of copying it, so there is only one version
to keep up to date. Add a short `CODE_OF_CONDUCT.md` to the repository:

```markdown
# Code of Conduct

This project follows the
[Millibar.io Code of Conduct](https://github.com/MBAR-Millibar/Code-of-Conduct/blob/main/CODE_OF_CONDUCT.md).
To report a concern, email [conduct@millibar.io](mailto:conduct@millibar.io).
```

See [docs/adopting.md](docs/adopting.md) for websites, apps, community channels
and events.

## 🤝 Contributing

Suggestions for clearer, fairer or more inclusive wording are welcome. Read
[CONTRIBUTING.md](CONTRIBUTING.md) first, and see [GOVERNANCE.md](GOVERNANCE.md)
for how changes are decided and released.

## 📁 Repository structure

```text
├── CODE_OF_CONDUCT.md        # Canonical English text
├── translations/             # One file per language (ISO 639-1 code)
├── docs/adopting.md          # How to use the code across Millibar spaces
├── CONTRIBUTING.md           # How to propose changes
├── TRANSLATING.md            # How to add or update a translation
├── GOVERNANCE.md             # Who decides, versioning, annual review
├── scripts/                  # Consistency checks run in CI
└── .github/                  # Issue/PR templates, CODEOWNERS, workflows
```
