# Using the Code of Conduct across Millibar spaces

The code is one document used everywhere. Link to it instead of copying it, so
there is only one version to keep up to date.

Canonical links:

- GitHub: `https://github.com/MBAR-Millibar/Code-of-Conduct/blob/main/CODE_OF_CONDUCT.md`
- Website: `https://millibar.io/code-of-conduct` (once published, tracked in MBAR-81 Part A)
- Reports: `conduct@millibar.io`

## GitHub repositories

For every repository in the `MBAR-Millibar` organisation, either:

- **Organisation default (recommended):** add a `CODE_OF_CONDUCT.md` to the
  organisation's `.github` repository. GitHub then shows it for every repository
  that has no file of its own.
- **Per repository:** add this `CODE_OF_CONDUCT.md`:

```markdown
# Code of Conduct

This project follows the
[Millibar.io Code of Conduct](https://github.com/MBAR-Millibar/Code-of-Conduct/blob/main/CODE_OF_CONDUCT.md).
To report a concern, email [conduct@millibar.io](mailto:conduct@millibar.io).
```

Also link it from each repository's `CONTRIBUTING.md`.

## Website and apps

- Publish the full text (and translations) on millibar.io, matching the version
  in this repository. Show the version number and the date.
- Show the page in the user's language when a translation exists, with a link to
  the English version.
- Link it in the footer of the website and in the settings or "About" screen of
  each app.
- Link it during sign-up for community features ("By joining, you agree to
  follow our Code of Conduct").

## Community channels and social media

- Pin a message with the link and the reporting address in every community
  channel (Discord, Slack, WhatsApp, Telegram…).
- Add the link to the channel description or rules.
- Moderators should know the reporting process before they start moderating.

## Events

- Link the code on the event page and in the registration confirmation.
- Mention it briefly at the start of the event, including how to report and who
  the on-site contacts are.
- Name at least one on-site contact, with a phone number, for the duration of the
  event.

## Contracts and onboarding

- Reference the code in contracts with team members, contractors, advisors and
  partners.
- Include it in onboarding, and collect an acknowledgement for each major
  version (see [GOVERNANCE.md](../GOVERNANCE.md#acknowledgement)).
